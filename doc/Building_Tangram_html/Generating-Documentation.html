3.4 Generating Documentation ¶

Lastly, if you need to generate a new edition of this manual or the user manual, you will need texinfo and texi2pdf and/or texi2any. If you have make there is a Makefile which will make running texinfo more convenient.

To generate the manuals in PDF, simply run: 

make pdf

if you have make, or: 

texi2pdf Building_Tangram.texinfo
texi2pdf Tangram.texinfo

To generate the manuals in HTML, run: 

make html

or: 

texi2any --html -c HTML_MATH=mathjax --split node Building_Tangram.texinfo
texi2any --html --split node Tangram.texinfo

which will produce the manuals under doc/Building_Tangram_html/index.html and doc/Tangram_html/index.html.
