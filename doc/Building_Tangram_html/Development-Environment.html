3.1 Development Environment ¶

Building the application .apk has been done using:

  • Java 21 (bundled with Android Studio)
  • Android Studio Quail (2026.1.1), downloaded from the official Android Studio web site.
  • Gradle 9.4.1, installed by running ./gradlew wrapper --gradle-version=9.4.1.
  • The Android Gradle Plugin version 9.2.1, as specified in the file gradle/libs.versions.toml.

See http://developer.android.com/sdk/index.html for information on how to set up a project using the Android SDK.
